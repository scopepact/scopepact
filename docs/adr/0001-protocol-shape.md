# ADR 0001: Security substrate with native and bridge profiles

Status: accepted for prototype.

The protocol will not compete with every application-level agent standard.
It defines an independent security, authority, commitment, and effect layer,
plus an optimized native task profile. A2A, MCP, x402, AP2, and SLIM are
integrated through profiles and adapters.

This preserves a coherent security model while allowing adoption inside
existing ecosystems.
