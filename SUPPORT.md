# ScopePact Support

ScopePact is a pre-release community project. Support is public and best-effort.

## Where To Ask

- Use [GitHub Discussions](https://github.com/scopepact/scopepact/discussions)
  for implementation questions, design exploration, adoption stories, and ideas
  that are not yet scoped work.
- Use [GitHub Issues](https://github.com/scopepact/scopepact/issues) for
  reproducible bugs, conformance gaps, and agreed implementation work.
- Use [GitHub private vulnerability reporting](https://github.com/scopepact/scopepact/security/advisories/new)
  for suspected vulnerabilities, as described in [SECURITY.md](SECURITY.md).

Before posting, include the ScopePact revision, runtime or platform, the command
you ran, the observed result, and the result you expected. Remove credentials,
private keys, user data, and confidential payloads.

There is no paid support tier for the public protocol and no payment changes
review priority or conformance status. Commercial services may exist outside
the community project, but they do not define official protocol behavior.
