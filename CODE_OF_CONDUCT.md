# Code Of Conduct

ScopePact contributors are expected to make technical collaboration safe,
direct, and productive.

## Expected Behavior

- Discuss ideas and evidence without attacking people.
- Give specific, actionable review feedback.
- Welcome questions from people with different protocol, security, language,
  and accessibility experience.
- State uncertainty, conflicts of interest, and security assumptions plainly.
- Respect privacy and coordinated vulnerability disclosure.
- Accept a maintainer decision while preserving technical dissent in the
  project record.

## Unacceptable Behavior

Harassment, discrimination, threats, doxxing, sexualized conduct, sustained
personal attacks, deliberate disruption, or publishing private vulnerability
details without coordination are not accepted in project spaces.

## Enforcement

Report conduct concerns privately to a project maintainer listed in
[MAINTAINERS.md](MAINTAINERS.md), using a private contact method from their
GitHub profile. Maintainers may edit or remove content, issue a warning,
temporarily restrict participation, or permanently remove a participant.
Decisions should consider safety, severity, repetition, and a fair opportunity
to respond.

This policy applies to repositories, issue trackers, reviews, discussions,
events, and public representation of the project.
